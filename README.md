# AP1 交互式2D分形 Sierpiński垫片
## 运行方式
使用静态HTTP服务器打开index.html，不支持file://本地直接打开，推荐VSCode Live Server。
本项目把教材Common库内置进代码，不需要外部js文件。

## 算法原理
1. **混沌游戏算法**：给定三角形三个顶点，取随机初始点。每次迭代取三角形随机顶点，新点 = (旧点+随机顶点)/2。大量迭代点收敛生成Sierpiński垫片，使用gl.POINTS渲染点云，支持点数随时间动画生长。
2. **递归细分subdivide(triangle, depth)**：输入三角形和递归深度depth。每次取三边中点，分割为4个子三角形；递归直到depth=0输出三角形顶点。
- depth=0输出原始三角形；depth越大分形细节越高。
渲染模式：
- POINTS：点云渲染细分顶点
- LINES：线框模式
- TRIANGLES：实体填充三角形

## 交互说明
UI面板：
- 渲染模式切换下拉
- 递归深度滑块（线框/实体模式生效）
- 点数量滑块（混沌游戏点云）
- 点大小滑块
- 三套配色切换

键盘快捷键：
`1`：点云模式；`2`：线框模式；`3`：实体模式；`空格`：暂停/继续点云生长动画。

鼠标：
- 画布左键按住拖拽：平移视图
- 鼠标滚轮：放大缩小视图
